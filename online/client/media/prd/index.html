音视频监控采集页面需求文档

1 项目概述

开发一个浏览器端单页面Web应用，基于Canvas进行实时渲染。页面同时调用相机、麦克风音频、录屏权限；画布底层背景渲染摄像头实时画面，叠加绘制监控格式时间戳、分贝仪表盘、分贝实时波形走势图，实现类似监控设备的画面+音频分贝可视化效果。

浏览器权限限制说明：录屏、摄像头、麦克风均要求HTTPS环境（localhost开发除外），部分浏览器录屏与摄像头不能同时打开，需要做异常捕获。

2 功能需求

2.1 权限授权模块

页面加载后引导用户申请三类媒体权限：

  1. 相机权限：获取摄像头视频流，作为Canvas底层背景画面
  2. 麦克风录音权限：采集环境音频，解析计算实时分贝值
  3. 录屏权限：获取屏幕共享流（可选，可切换：摄像头画面 / 屏幕画面作为背景源）

权限异常处理：

  • 用户拒绝任一权限，给出友好提示，展示失败原因
  • 浏览器不支持对应API时，做降级提示
  • 设备断开（摄像头拔掉、麦克风断开）捕获错误并展示提示

2.2 Canvas实时绘制总逻辑

整个页面渲染全部由单个Canvas完成，不使用DOM元素叠加；所有内容绘制在同一画布，循环requestAnimationFrame刷新。 绘制层级（由底到顶）：

  1. 底层：视频源画面（摄像头 / 录屏共享画面，铺满Canvas画布）
  2. 上层叠加元素：左上角时间文本、右上角分贝仪表盘、仪表盘下方分贝波形曲线图

2.3 左上角：实时时间绘制

  1. 位置：Canvas左上角
  2. 格式：YYYY‑MM‑DD HH:MM:SS，例如：2026‑10‑15 14:30:22
  3. 样式：小字号，白色字体，增加黑色描边/阴影，模拟监控摄像头OSD时间，保证在复杂画面上清晰可读
  4. 更新：每秒更新一次时间显示

2.4 右上角：分贝仪表盘（参考截图UI）

位置：画布右上角区域

  1. 表盘：弧形刻度仪表盘，刻度范围：0 ~ 120分贝；刻度标记：0、20、40、60、80、100、120
  2. 红色指针：跟随实时分贝转动
  3. 表盘中心展示当前实时分贝大数字 XX分贝
  4. 辅助文本参考示例：40dB：安静的图书馆（显示参考环境描述）
  5. 统计数值展示（仪表盘下方）
    • 最小分贝：本次会话采集到的最低分贝
    • 平均分贝：本次会话分贝算术平均值
    • 最大分贝：本次会话采集到的最高分贝

2.5 分贝实时波形走势图（参考截图）

位置：仪表盘正下方

  1. X轴：时间（秒），保留最近15秒音频数据，旧数据自动向左滚动移出视图
  2. Y轴：分贝数值范围0‑120
  3. 绘制：红色波形线条，曲线下方填充淡红色半透明底色
  4. 坐标轴标注刻度：0、20、40、60、80、100、120分贝

2.6 分贝计算逻辑

浏览器AudioContext拿到的是音频振幅，需要转换为人耳感知分贝(dB)

  1. 采集麦克风PCM音频，计算音频RMS均方根振幅
  2. 振幅映射转换为0‑120分贝数值
  3. 做防抖平滑处理，避免数值剧烈抖动跳动
  4. 持续维护：min（最小值）、max（最大值）、累计总和用于计算average平均分贝

3 UI视觉规范

  1. 整体：Canvas自适应窗口大小，窗口resize时重新调整画布尺寸
  2. 仪表盘：弧形半圆样式，浅灰色刻度，红色指针，与截图样式保持一致
  3. 波形图：红色曲线，区域填充淡红色半透明
  4. 文字：监控OSD风格，白色文字带黑色外描边，保证在明暗画面都可读

4 非功能需求

  1. 性能：requestAnimationFrame驱动渲染，尽量降低CPU占用；画布渲染帧率跟随显示器刷新率
  2. 兼容性：Chrome、Edge；Safari部分媒体API存在差异，需要做兼容判断
  3. 错误捕获：所有媒体设备调用全部增加try‑catch；权限拒绝、设备丢失要有UI提示
  4. 切换能力：支持切换背景源：【摄像头画面】 / 【录屏屏幕共享画面】

5 输入输出&边界说明

  1. 分贝是环境音频相对计算值，不是专业声学仪器，仅做可视化展示，精度做备注说明
  2. 录屏：浏览器屏幕共享只能获取屏幕画面，录屏本身不采集麦克风音频；音频独立来自麦克风设备
  3. 浏览器限制：部分移动端浏览器不支持同时开启摄像头+屏幕共享，需要捕获异常并提示用户
