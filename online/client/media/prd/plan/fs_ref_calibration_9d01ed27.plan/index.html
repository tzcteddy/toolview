满幅校准滑块

按前面沟通：用户用滑块调节 0 dBFS 对应多少分贝，对表后这台设备读数才有日常参考意义。不改侧栏/主题，不恢复「锁到 40」。

行为

  • 显示：Lp = 10·log10(ms) + fsRef + trim + drift
  • fsRef 出厂 100（安静室内大约回到 35–45，消掉现在相对旧版多出的约 20 dB）
  • 范围 90–120，步进 1；即时生效，Lp / Leq / dBC / 原始共用
  • 重置默认值：fsRef=100
  • 底噪跟踪、1.5s 校准中 职责不变（跟踪不瞄 40；校准中只稳定滤波器）

改动

只动 packages/toolkit-online/src/pages/media/。

1. 配置

settings.ts：

  • 增加 fsRef: number
  • DEFAULT = 100
  • SETTINGS_RANGE.fsRef = { min: 90, max: 120 }
  • normalize：缺字段用 100，并 clamp

2. 表计

audio-meter.ts：

  • 去掉写死 FS_REF = 120
  • 增加 setFsRef(n)，toDb() 用当前 fsRef
  • 默认 100，与设置同步

3. 设置 UI（沿用现有 row + range）

MediaSettings.vue 在「底噪自动跟踪」上方增加：

  • 标签：满幅参考 {{ settings.fsRef }}dB
  • input.range min 90 max 120
  • 旁注：数值越大同一环境读数越高；可用手持声级计对照后调节

MediaMonitor.vue：applyMeterFromSettings / onPatch 里调用 meter.setFsRef(settings.fsRef)。可写 canvas.dataset.fsRef 方便验收。

验收

chrome-devtools /media：

  1. 出厂/重置：fsRef=100，安静读数明显低于现在的「120 刻度」（约低 20 dB）
  2. 滑块拖到 120：同一信号升高约 20；拖到 90：再降
  3. A/C 差值、勾选规则、C 开关、底噪跟踪、齿轮/铺满不回归
