监控页 C 计权（prd4）

对照 prd4.md。只改 pages/media/，不改侧栏/主题。V1–V3 全保留：关 C 计权后计算与画面必须和现在完全一样。

和 V3 的对齐

  • 默认只开 A 计权：enableCWeight=false。此时不建 C 权值、不累积 Leq(C)、不画 C/原始曲线，CPU 与 V3 相同。
  • V3 的 showLp / showLeq 仍只管 A 路展示（红 LpA、蓝 Leq(A)），全取消仍强制勾回 Lp。
  • 「选项下拉」落到现有【UI配置】复选/开关，不新增异形下拉，避免换皮。
  • 表盘大数字和红指针仍跟 LpA（V3 不变）。C 开后统计区多一组 dBC。

配置

settings.ts 仍用 toolkit-media-settings，缺字段补默认：

  • enableCWeight：出厂 false
  • showRaw：出厂 true（仅 C 开启时生效）
  • showLpC：出厂 true（仅 C 开启时生效）
  • showLeqC：出厂 true（仅 C 开启时生效；与 showLeq 独立：Leq(A)/Leq(C) 可同时画）
  • 重置：全部出厂，并停 C 路、清 C 波形/能量窗

音频（AudioMeter）

改 audio-meter.ts。主路径仍是一帧一次 getFloatFrequencyData（fft 2048），不要再开第二条 Analyser。

Analyser FFT
 ├─ 无计权能量 → 原始声压 LpZ（仅 enableCWeight）
 ├─ × A 曲线 → 时间加权 → 底噪 → LpA / Leq(A)   （始终，与 V3 相同）
 └─ × C 曲线 → 时间加权 → 同一偏移 → LpC / Leq(C) （仅 enableCWeight）
  • C 权：ISO 226 / IEC 61672 C 曲线（cWeightDb(freq)，与现有 aWeightDb 并列）；Biquad 缺失时仍走频域；再不行 RMS 降级，C 用同一 RMS 仅作占位（验收仍要有 dBC 数）。
  • setCWeightEnabled(false)：停 C 累加、丢 C 缓冲，下一帧不再乘 C 权。
  • 开启 C：用当前 A 校准 offset，不重新校准；LpC/Leq(C) 钳 0–120。
  • MeterSnapshot 增补：dbC、leqC、dbRaw（C 关时为 0 且 UI 不读）。
  • 缓冲：getRawWaveform() / getLpCWaveform() / getLeqCWaveform()；waveDuration 仍只裁 X 轴。

设置弹窗

MediaSettings.vue 新项放在【UI配置】噪声算法下面：

  • 开关：启用C计权并行测量（默认关）
  • C 开后显示复选：原始声压、LpC、Leq(C)（与 LpA / Leq(A) 并列）；旁注「并行会增加少量计算」
  • 移动端（已有 isMobile）再加一行：算力消耗较大，可关闭 C 计权
  • 底部署名改为 prd4 文案： 「A计权用于日常环境噪声评估；C计权适合冲击、低频噪声测量。本模拟结果仅作参考，非专业计量设备。」
  • 即时生效，不关采集、不关 rAF

  • 红 Lp瞬时 / 蓝 Leq等效Leq；统计 Leq：XX dB 仍为 Leq(A)

  • 悬停：Canvas mousemove 命中波形区时，竖线 + 文案读该时刻 LpA / LpC（无点则不画）；不引入 DOM 图例

测试（prd4 §7）

chrome-devtools /media（mock 麦 + 可调增益）：

  1. 默认：无 dBC、无灰/橙曲线，Lp/Leq 与 V3 相同（安静约 35–45）
  2. 勾选 C：出现 dBA+dBC、4 条曲线与图例；低频/增益升高时 dBC 不低于 dBA
  3. 悬停波形：能读到 A/C 分贝
  4. 取消 C：C 曲线/读数消失，Leq(A)/LpA 不被清空
  5. 重置：C 关，文案与算法回到出厂
  6. 视频/录屏/齿轮/右侧铺满不回归
