监控页 Lp / Leq（prd3）

对照 prd3.md 全文（含 3.1–3.6、第 4–7 节）。只改 pages/media/，不改侧栏/主题。V1/V2 能力全部保留：单 Canvas、摄像头/录屏、OSD、表盘、齿轮弹窗、原有功能/UI 滑块、权限与 resize。

和上一版 plan 对齐的需求要点

  • 底层始终并行算 Lp + Leq，勾选只控制「画不画 / 显不显」，不算不算。取消再勾选 Leq 时立刻有数据。
  • 表盘大数字和红指针永远跟 Lp，即使只勾选了 Leq。
  • 多选只影响：波形曲线、图例、Leq 统计行。Lmin / Avg / Lmax 始终基于 Lp，一直显示。
  • 全取消算法 → 强制勾回 Lp（不能空）。
  • 链路按 3.5：麦克风 → AnalyserNode → A 计权 → 时间加权 → 底噪补偿与平滑，再分叉 Lp / Leq。
  • Leq 是 声能量积分（10*log10(mean(10^(L/10))) 或等价均方能量），不是 Lp 算术平均；短突发会抬高，消失后缓慢回落，不会瞬间归位。
  • 图例 Canvas 内右上，文案按 PRD：Lp瞬时、Leq等效Leq；未勾选的曲线和图例一起消失。
  • 统计文案改为 最小(Lmin) / 平均(Avg) / 最大(Lmax)；勾选 Leq 时多一行 Leq：XX dB。
  • 弹窗底部加 3.6 提示；画布底部原有「非专业声级计」备注保留。
  • 响应速度三档对应声级计 Fast / 自定义 / Slow（标签 快/中/慢）。
  • 开麦初期校准 UI 必须显示「校准中…」，完成后再出数。
  • AudioContext 挂起要 提示用户，不是只 resume()。
  • Safari 无 A 计权滤波时降级优化 RMS，Lp 与 Leq 仍要能算。

原有 videoEnable、micEnable、gaugeScale、timeFontSize、waveDuration 不变。重置：全部恢复出厂，并清空 Leq 能量窗 + Leq 波形（Lp 统计一并按现有重置逻辑清会话）。

waveDuration（5–30s）只裁 两条曲线的 X 轴历史；leqWindow（5–60s）只改 Leq 积分周期，二者独立。

音频（AudioMeter）

重写 audio-meter.ts。无论勾选如何，tick 都更新 Lp 与 Leq。

MediaStreamSource → AnalyserNode(fftSize 2048)
                 → A 计权（优先频率权曲线乘 FFT 能量；有 Biquad 时也可接在 Analyser 前，等价）
                 → 均方时间加权（Fast/自定义/Slow）+ 少量平滑
                 → 底噪补偿 → Lp（0–120）
                 → 同一线性能量按 leqWindow 积分 → Leq（0–120，禁止负数）

实现约束（prd 7.1 / 7.2）：

  • 每帧只读 Analyser + O(fftSize) 权值累加 + O(1) 环形能量窗，不在主线程做重 FFT。
  • A 计权滤波能放到 BiquadFilterNode 的就放音频图（音频线程）；不行则用频域 A 曲线；再不行降级 RMS（5.4）。
  • createBiquadFilter / getFloatFrequencyData 缺失走降级，Lp、Leq 仍输出。

底噪：

  • start() / 再次开麦：约 1.5s 校准，calibrating=true，画布「校准中…」，此间不把 Lp 写成 0 充统计。
  • 校准目标：安静室内 Lp 落在 35–45（验收 6.1），不再 (dBFS+60)*2 那种低音量直接 0。
  • noiseFloorTrack=true：接近基线时缓慢跟踪；false：只用这次校准的固定基线。

Leq：

  • 对 A 计权后的线性能量（或 10^(Lp_raw/10)）做窗口平均，再换成显示 dB，与 Lp 同一校准偏移，便于和 35–45 对齐。
  • 改 leqWindow：只清 Leq 能量队列和 Leq 波形，不动 Lp 波形与 Lmin/Avg/Lmax。
  • 响应速度只改 Lp 时间常数，Leq 不吃这个参数（验收 6.6）。

关麦：setActive(false)，曲线贴基线平线，统计冻结（含 Leq 文本若在展示）。

AudioContext suspended：resume()，失败把错误写到现有画布错误条（3.5.3）。

MeterSnapshot：db(Lp)、leq、min、max、avg、calibrating；getWaveform() 与 getLeqWaveform() 两条缓冲。

设置弹窗

MediaSettings.vue 新项只放在【UI配置】原滑块下面，功能配置不动：

  • 复选：Lp瞬时分贝、Leq等效连续噪声；全取消 → patch 强制 showLp
  • 滑块：Leq 积分窗口 5–60s，显示当前秒数；!showLeq 时 disabled + 置灰
  • 滑块：响应速度 0–2，旁注 快 / 中 / 慢
  • 开关：底噪自动跟踪
  • 弹窗底部（分组外、按钮上方或页脚上）固定文案： 「提示：本页面基于浏览器麦克风模拟声级计，非专业声学计量仪器，测量结果仅供参考。」

全部即时生效，不关采集、不关 rAF。

测试（prd3 第 6 节）

chrome-devtools /media（有麦用真麦，否则 mock 流 + 可调增益）：

  1. 开麦出现「校准中…」，结束后安静环境 Lp 约 35–45，不再贴 0；Leq 缓缓靠拢
  2. 短突发：Lp 冲高，Leq 慢抬；声停后 Leq 慢回，不瞬间掉回
  3. 取消 Leq：蓝线、Leq等效Leq 图例、Leq： 文本消失，只留红 Lp
  4. 再勾选 Leq：蓝线、图例、统计恢复
  5. 只留 Leq：只有蓝线+蓝图例，表盘仍跟 Lp；Leq 窗口滑块可用。取消 Leq 后滑块置灰
  6. 改 Leq 窗口：蓝线重积、快慢明显变；红线与 Lmin/Avg/Lmax 不被清空
  7. 改响应速度：红线阻尼变，Leq 不明显跟
  8. 全取消算法 → Lp 被强制勾回
  9. 关麦：平线、统计停；重置：Lp+Leq 都勾、窗口 10、响应快、底噪跟踪开
  10. 视频开关、录屏/摄像头、齿轮、resize、侧栏「监控」不回归
