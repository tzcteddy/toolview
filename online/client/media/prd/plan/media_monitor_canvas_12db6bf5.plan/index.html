音视频监控采集页

在 packages/toolkit-online/src/pages/media/index.astro 落地 prd.md。现页为空；站点是 Astro + Vue3，按现有页面模式用 Vue 组件 + client:load 承载全部逻辑。

页面接入

  • index.astro 使用现有 PageLayout + Layout（isFullScreen + hideHeader），主区只挂一个全高 Vue 组件，不叠加其它 DOM。
  • 在 packages/toolkit-online/src/layouts/Side.astro 增加「监控」入口（id: media, link: /media），否则路由无法从站内到达。
  • 画布铺满主内容区（侧栏保留，与其它频道一致）；resize 时同步 canvas.width/height（乘 devicePixelRatio）。

权限与源切换

加载后先画「点击授权」引导（getUserMedia / getDisplayMedia 需要用户手势，不能裸 onload 弹框）。

  1. 点击后申请 摄像头 + 麦克风（video + audio）。
  2. 录屏按需：点「屏幕画面」时再 getDisplayMedia({ video: true })；录屏流不含麦克风，音频始终走独立 mic。
  3. 默认背景：摄像头；画布右下画两个命中按钮：摄像头 / 录屏。
  4. 异常全部 try/catch，画在画布上：
    • 拒绝权限 / 不支持 API / NotFoundError / NotReadableError
    • video/audio 的 ended/inactive（设备拔出、停止共享）
    • 部分浏览器无法同时开摄像头+录屏：捕获后提示并保持当前可用源

分贝计算

AudioContext + AnalyserNode（fftSize 2048，时域 getByteTimeDomainData 或 float PCM）：

  • rms = sqrt(mean(samples^2))
  • dBFS = 20 * log10(rms)，rms=0 时按静音
  • 映射到 0–120：db = clamp((dBFS + 60) * 2, 0, 120)（约 -60dBFS→0，0dBFS→120）
  • 指数平滑：smoothed += (db - smoothed) * 0.15
  • 会话统计：min、max、sum/count → avg
  • 波形缓冲：每帧压一个平滑值，只保留最近 15 秒（按时长裁切，不按固定帧数）

画布底部小字备注：分贝为相对可视化，非专业声级计。

参考文案按当前 dB 档位切换，例如：

  • ~40：安静的图书馆
  • ~60：正常交谈
  • ~80：繁忙街道
  • ~100：地铁/嘈杂车间

Canvas 绘制层（底→顶）

每帧 requestAnimationFrame：

  1. 铺满视频：drawImage(video, 0, 0, w, h)；无画面时深色底 + 提示。
  2. 左上 OSD：YYYY-MM-DD HH:MM:SS，小字白字 + 黑描边/阴影；时间字符串每秒更新。
  3. 右上半圆弧表盘 0–120，刻度 0/20/…/120；红指针跟平滑分贝；圆心大号 XX分贝；下方参考环境句。
  4. 表盘下三行：最小 / 平均 / 最大。
  5. 再下方 15 秒红色波形 + 淡红半透明填充；Y 轴同样 0–120 刻度。
  6. 右下源切换按钮、错误条、精度备注（均在同一 canvas）。

仪表盘用浅灰刻度、红色指针，贴合 PRD 监控风，不改站点侧栏/主题变量。

交互命中

在 Vue 里对 canvas click 做坐标换算（考虑 DPR），检测授权按钮、源切换、重试区域。

测试

按 feature skill：启动 toolkit-online dev，用 chrome-devtools 打开 /media，验证：

  • 拒绝/允许相机与麦克风后的画布提示与画面
  • 分贝数字、指针、波形随声音变化，min/avg/max 更新
  • 切换录屏（可能需用户手势）及停止共享后的回退/提示
  • 窗口 resize 后面画铺满且 overlay 位置正确
  • 侧栏「监控」可进入该页
