监控页设置弹窗（prd2）

在现有 packages/toolkit-online/src/pages/media 上迭代，保留单 Canvas 采集/OSD/表盘/波形/源切换。设置入口和弹窗是 DOM（prd2 明确不画进 canvas）。配置只放 pages/media/，不改侧栏/主题公共组件。

配置状态

新增 pages/media/lib/settings.ts：

{
  "videoEnable": true,
  "micEnable": true,
  "gaugeScale": 100,
  "timeFontSize": 16,
  "waveDuration": 15
}
  • localStorage key：toolkit-media-settings；读入时校验范围（gauge 30–100、字号 12–36、波形 5–30）
  • 「重置默认值」写回上述默认并立刻重绘、清空波形缓存
  • 「关闭」只关弹窗，当前值已实时写入 storage

设置 UI（DOM）

在 MediaMonitor.vue 上叠加，或拆 MediaSettings.vue：

  • 右下角固定齿轮按钮（@iconify/vue，如 material-symbols:settings-outline）：半透明底、hover 高亮，z-index 高于 canvas
  • 为避免挡住 canvas「摄像头/录屏」，画布源按钮左移约 56px（renderer.ts）
  • 弹窗：遮罩 + 白底圆角「参数配置」；分组【功能配置】【UI配置】；行内 label + 控件；小屏 max-height + 内容滚动
  • 开关/滑块用原生 input[type=checkbox] / range，样式贴合站点 --primary / --danger，不引入新 UI 库
  • 关闭：再点齿轮 / 点遮罩 / 「关闭」
  • 打开弹窗时 rAF 与媒体流不停
  • 轻量 toast（DOM）：翻转失败、录屏下关视频开关

功能配置：

项行为
开启视频画面仅控制摄像头是否 drawImage；关 → 纯黑底。当前源是录屏时开关无效，toast「当前背景源为屏幕共享，视频开关不生效」
开启麦克风不释放权限；关 → AudioMeter 暂停采样，指针 0、波形平线、画布字「麦克风已关闭」；开 → 原流恢复 tick
翻转摄像头isMobileDevice() 才显示；facingMode user/environment 互换；失败 toast「无法切换摄像头，设备不支持」，画面不变

UI 配置（拖滑条即生效）：

  • 仪表盘大小：gaugeR *= gaugeScale/100
  • 字体大小：OSD 时间用 timeFontSize（白字+阴影不变）
  • 波形时长：AudioMeter.setWindowMs(n * 1000) 并 清空 旧波形

采集 / 绘制接线

flowchart LR
  gear[GearDOM] --> modal[SettingsModal]
  modal --> cfg[SettingsState]
  cfg --> ls[localStorage]
  cfg --> raf[rAF_renderMonitor]
  cfg --> meter[AudioMeter]
  flip[FlipCamera] --> perm[permissions.facingMode]
  • permissions.ts：requestCamera(facingMode)；翻转只换视频轨，麦克风流保持
  • audio-meter.ts：windowMs 可设、setActive(false) 时 tick 返回 0 且不写 wave/统计
  • renderer.ts：RenderState 增加 videoEnable、micEnable、gaugeScale、timeFontSize、waveDuration；hasVideo 在 camera + !videoEnable 时为 false

测试

toolkit-online dev + chrome-devtools /media：

  • 齿轮打开/关闭弹窗，底层时间与波形仍在走
  • 关视频：摄像头源变黑底；录屏源时 toast 且画面仍在
  • 关麦克风：指针 0、平线、「麦克风已关闭」；再开恢复
  • 三滑块实时变；改波形时长后曲线清空再涨
  • 重置恢复默认；刷新后 localStorage 配置仍在
  • emulate 窄屏/touch：出现翻转按钮；PC 无此按钮
  • 源切换、resize、侧栏「监控」不回归
