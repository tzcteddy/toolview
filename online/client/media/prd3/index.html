音视频监控采集页面｜V3迭代版本需求文档（新增Leq等效连续噪声、多算法切换）

基于V1全部能力迭代；解决原始音频分贝低音量直接归零问题，增加 Leq等效连续A声级；支持在配置面板多选启用噪声算法；Canvas走势图绘制多条曲线、颜色区分，附带图例；原有摄像头、录屏、设置弹窗、Canvas监控画面全部保留。 重要说明：浏览器麦克风仅为模拟声级计，非专业计量设备，测量结果仅供参考。

1 历史版本继承

  1. V1全部功能：Canvas整体渲染，底层摄像头/录屏画面；左上角时间戳；右上角分贝仪表盘；右下角悬浮齿轮⚙️设置弹窗；
  2. 设置弹窗原有配置：视频开关、麦克风开关、翻转摄像头；仪表盘大小、字体大小、波形时长滑块、重置默认值；
  3. 媒体权限、设备异常捕获、窗口resize自适应、录屏/摄像头源切换逻辑全部保留；
  4. V3基础音频优化：A计权模拟、底噪自动校准、Fast时间加权、信号平滑，解决安静环境分贝直接归零缺陷。

2 现存问题（迭代出发点）

  1. 旧逻辑简单RMS换算分贝，安静环境直接输出0dB，微弱环境噪声无法体现；
  2. 只有瞬时单种分贝数据，缺少国标噪声评估指标 Leq等效连续噪声；
  3. 无法对比查看「瞬时噪声」和「一段时间能量加权噪声」；
  4. 波形图仅展示单条数据线。

3 新增核心需求

3.1 支持两套噪声算法输出

同时并行计算2套噪声数据，底层持续运算，上层按需选择展示：

  1. Lp 瞬时A计权分贝（原始实时值）
    • 声级瞬时值，跟随环境声音快速变化，用于仪表盘指针；
  2. Leq 等效连续A声级（能量平均）
    • 按照噪声国标公式做声能量积分平均，不是分贝算术平均；短暂高分贝噪音会拉高Leq；数值变化平缓，用于评估一段时间噪声暴露。

Leq可配置积分窗口：计算统计的时间周期。

3.2 设置弹窗新增配置项

放置于弹窗【UI配置】分组下

配置项控件取值说明
噪声算法（多选）复选框☑ Lp瞬时分贝、☑ Leq等效连续噪声勾选哪些算法，波形图就绘制对应曲线；至少强制勾选1项，不可全部取消；修改实时生效
Leq积分窗口时长滑块5‑60秒Leq能量累积计算的时间窗口；修改会清空Leq历史缓存，重新开始累积；仅勾选Leq时该配置项启用，否则置灰不可操作
响应速度滑块快/中/慢对应声级计Fast/自定义/Slow时间加权，控制Lp瞬时分贝指针响应快慢，实时生效

默认出厂配置：同时勾选 Lp瞬时分贝 + Leq等效连续噪声；Leq窗口=10秒；响应速度=快；底噪自动跟踪=开启。

3.3 分贝仪表盘逻辑变更

  1. 仪表盘大数字、红色指针：固定展示 Lp 瞬时分贝（人直观感知的实时噪音）；
  2. 仪表盘下方统计区：
    • 保留原有：最小(Lmin)、算术平均(Avg)、最大(Lmax)
    • 新增 Leq：XX dB；当未勾选Leq算法时，该文本隐藏；

说明：Lmin/Avg/Lmax依旧基于瞬时Lp数据统计。

3.4 分贝走势图（波形图表）重大变更

原单曲线改为多曲线绘制，全部绘制在同一个图表画布区域，X轴统一为时间秒，Y轴统一0‑120分贝。

  1. 每条算法数据线使用固定区分颜色
    • Lp瞬时分贝：红色曲线 + 下方填充淡红色半透明（保持原有UI不变）
    • Leq等效连续噪声：蓝色曲线 + 下方填充淡蓝色半透明
  2. 图例绘制：图表内部右上角绘制图例，和曲线颜色一一对应：🔴 Lp瞬时、🔵 Leq等效Leq；未勾选的算法自动隐藏对应曲线+图例。
  3. 时间轴：波形时长沿用原有配置滑块，统一控制所有曲线保留的历史数据长度。
  4. 数据行为：
    • Lp曲线：快速跟随噪音上下跳动；
    • Leq曲线：变化平缓，不会剧烈跳动；突发巨响后会缓慢抬升，之后缓慢回落；
  5. 交互约束：如果仅勾选其中一项，图表只渲染单条曲线，图例只显示对应一项，兼容旧版视觉效果。

3.5 音频处理完整链路

麦克风音频流 → AnalyserNode → A计权模拟滤波 → 时间加权(Fast/中/慢) → 底噪补偿与平滑
├─→输出【Lp瞬时分贝】用于仪表盘、Lmin/Lmax/Avg统计、Lp波形
└─→持续累积声压能量，按配置窗口积分计算【Leq等效连续噪声】，用于Leq文本展示、Leq波形曲线
  1. 麦克风打开初期：执行底噪校准，UI显示“校准中…”，校准完成输出数值；
  2. 麦克风关闭：所有曲线归零，波形为平线，统计数据暂停更新；
  3. 浏览器音频上下文挂起，捕获异常给出提示。

4 UI视觉规范

  1. 波形图：多条曲线共存，各自半透明填充，线条有足够对比度，避免视觉混淆；
  2. 图例绘制在波形图内部右上角，Canvas绘制（非DOM）；勾选状态变化实时增删图例、曲线；
  3. Leq积分窗口滑块：未勾选Leq时置灰，不可操作；
  4. 所有参数修改全部实时生效，无需确认按钮，不中断音视频采集。

5 边界与异常处理

  1. 算法多选框禁止全部取消；用户取消全部时自动强制勾选Lp瞬时分贝；
  2. 修改Leq积分窗口：清空Leq能量累积缓存、清空Leq历史波形数组，重新开始计算；Lp数据不受影响；
  3. 关闭麦克风：两条曲线全部置为基线占位，统计项停止更新；
  4. 移动端Safari音频API降级：无法实现A计权滤波时，降级优化RMS算法，Lp与Leq依然可以继续计算；
  5. Leq不会出现负分贝，计算结果钳位到 0‑120dB区间。

6 验收测试标准

  1. 安静室内环境，Lp输出35‑45dB，不再直接归零；Leq缓慢收敛到相近数值；
  2. 制造短暂突发噪音：Lp瞬间冲高，Leq缓慢抬升，噪音消失后Leq平缓回落，不会瞬间归位；
  3. 设置面板取消勾选Leq：波形蓝色曲线、图例、Leq统计文本全部消失；仅保留红色Lp曲线；
  4. 重新勾选Leq：蓝色曲线、图例、Leq统计恢复；
  5. 修改Leq积分窗口，Leq响应快慢发生明显变化；窗口控件未勾选Leq时置灰；
  6. 修改响应速度，Lp曲线跳动阻尼发生变化，Leq不受该参数影响；
  7. 重置默认值，恢复为同时勾选Lp+Leq，全部参数恢复出厂。

7 非功能需求

  1. 音频运算在WebAudio音频线程完成，不阻塞主线程Canvas渲染，保证画面流畅；
  2. 增加Leq计算不带来明显CPU开销；
  3. 完全向下兼容V1，原有逻辑不受破坏。
